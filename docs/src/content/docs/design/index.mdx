One of the major goals of DPScript is to create a friendly, clear, concise, and safe language that still feels native to Minecraft. This means a few things:

<Steps>
    1. The language has many high-level things, like variables, enums, functions, loops, and conditionals.
    2. The compiler will check your types and help to ensure there's no undefined values.
    3. The compiler will translate your code into a Minecraft datapack that should just simply work.
    4. Compilation errors should be helpful - they should show you where and what the issue is, and potentially even how to fix it.
</Steps>

A lot of these principles come from my experience with Rust, which also does similar things, but I want to keep the learning curve very light with DPScript.
No borrow checking, just a safe, efficient, and easy-to-use language with concise syntax.
